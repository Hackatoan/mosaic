# Mosaic

Free photomosaic generator — rebuild any image out of hundreds of smaller tile photos.

🔗 **Live:** [mosaic.hackatoa.com](https://mosaic.hackatoa.com)   ·   ☕ **Support:** [Buy Me a Coffee](https://buymeacoffee.com/hackatoa)

## Overview

Upload a source image and Mosaic reconstructs it from a grid of tile images matched by average color. Tiles can come from your own uploads, a Pexels topic search, or a shared Drive folder. Results can be shared via opt-in links.

## Features

- Tiles from uploads, Pexels topic search, or a Drive folder
- Average-color tile matching
- Opt-in shareable result links
- 6-language localization

## Tech Stack

Next.js · JavaScript · Docker

## Development

```bash
npm install
npm run dev
```
